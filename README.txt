تحديث شجرة عائلة شما
=====================
1) انسخ الملفات فوق مشروعك مع الحفاظ على المجلدات:
   app.py, kinship.py, tree_pdf.py, requirements.txt      -> جذر المشروع
   templates/tree.html, templates/relationship.html       -> مجلد templates
   static/fonts/Amiri-*.ttf                               -> مجلد static/fonts (أنشئه إن لم يوجد)
2) احذف templates/tree_branch.html (لم يعد مستخدماً).
3) نفّذ:  pip install -r requirements.txt
4) أعد تشغيل التطبيق.
الخط Amiri بترخيص SIL OFL (مسموح بتضمينه).
